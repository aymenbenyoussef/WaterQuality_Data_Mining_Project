# Analyse de la Qualité de l'Eau

## 📌 Description du Projet
Ce projet de **Data Mining** a pour objectif d’analyser la qualité de l’eau à partir de différentes variables physico-chimiques et environnementales.  
L’objectif principal est d’exploiter les données afin de détecter les facteurs influençant la qualité de l’eau et de construire des modèles prédictifs permettant d’évaluer son état.

## 📊 Méthodologie

### 1. Collecte des Données
Récupération d’un dataset contenant plusieurs paramètres liés à la qualité de l’eau.

### 2. Prétraitement
- Gestion des valeurs manquantes  
- Suppression des doublons  
- Normalisation des données  
- Encodage si nécessaire  

### 3. Analyse Exploratoire
- Statistiques descriptives  
- Corrélations entre variables  
- Visualisations graphiques  

### 4. Modélisation
Application de plusieurs algorithmes comme :

- Random Forest  
- SVM  
- Decision Tree  
- Logistic Regression  

### 5. Évaluation
Utilisation de métriques telles que :

- Accuracy  
- Precision  
- Recall  
- F1-score  
- Matrice de confusion
